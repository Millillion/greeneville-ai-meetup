# Greeneville AI Meetup

Materials for the Greeneville AI Meetup in Greeneville, Tennessee. Hosted by [Millillion](https://millillion.org/meetup/).

## November 12, 2026: What AI Can Do for You

Thursday, November 12, 2026, 7–9pm, Big Spring Room, Greeneville/Greene County Public Library, 210 N Main St.

- Slides: https://millillion.github.io/greeneville-ai-meetup/
- PDF: https://millillion.github.io/greeneville-ai-meetup/slides.pdf
- Source: [slides.md](slides.md) ([Marp](https://marp.app/) Markdown)

## Building the slides

```bash
npm install
npm run build   # dist/index.html
npm run pdf     # dist/slides.pdf (needs Chrome)
npm run watch   # rebuild on save
```

Open `dist/index.html` in a browser to present. Arrow keys move between slides, F goes full-screen, P opens presenter view with notes.
